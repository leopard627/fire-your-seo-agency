# 로컬 SEO — Google Business Profile 점검

방문·출장 고객이 업체를 정확히 찾고 연락할 수 있는지 확인한다.
업체 적격성, 공개 정보, 관리자 계정에서만 볼 수 있는 상태를 구분한다.

## 1. 대상과 접근 범위

- [ ] 사업 형태, 실제 운영 지역, 고객 대면 방식, 공식 사이트, 기존 프로필 URL을 확인한다.
- [ ] [등록 적격성](https://support.google.com/business/answer/13763036?hl=en)을 먼저 검토한다.
      온라인 전용 사업이나 대표 권한이 없는 장소의 수업·모임에 프로필을 권하지 않는다.
      계절 업체 등 예외 조건도 확인하며, 불명확하면 '적격성 미확인'으로 표시한다.
- [ ] 방문형/출장형/혼합형을 구분한다. 주소를 보여야 하는 업체인지 먼저 판단한다.
- [ ] 관리자 연결이 없으면 공개 프로필·공식 사이트·제공 자료로 진행한다.
      소유권·인증·정지·심사 중인 수정·성과 데이터는 공개 화면만으로 확정하지 않는다.
- [ ] 이미 허용된 관리 범위에서 작업한다. 감사 요청만으로 프로필을 새로 만들거나
      소유권을 주장하지 않는다. 계정 접근이 없어도 공개 점검과 수정안은 완성한다.

## 2. 공개 프로필과 실제 업체 대조

아래 항목을 [업체 표시 기준](https://support.google.com/business/answer/3038177?hl=en)에 맞춰 대조한다.

| 항목 | 확인할 내용 | 기록할 근거 |
|---|---|---|
| 상호 | 실제 간판·브랜드명, 지역/홍보 키워드 임의 추가 여부 | 프로필·공식 사이트·제공 자료 |
| 주소/서비스 지역 | 실제 운영지, 지도 핀, 고객 방문 여부에 맞는 표시 | 공개 주소·운영 방식 |
| 카테고리 | 핵심 업종에 맞는 주 카테고리와 필요한 추가 항목 | 현재 표시·실제 서비스 |
| 전화·사이트 | 해당 업체 연락처와 올바른 지점/서비스 페이지 | 링크 목적지·번호 대조 |
| 운영시간 | 실제 고객 응대 시간, 예약제·계절 운영 여부 | 공식 안내·제공 일정 |
| 리뷰·사진 | 고객 질문에 유용한 답변, 현재 시설·서비스와의 일치 | 확인 날짜·표본 URL |
| 중복 | 같은 업체의 이전 이름·주소 프로필 후보 | 각 프로필 URL·차이 |

- 출장형 업체의 비공개 주소를 일관성 점검을 이유로 사이트에 공개하지 않는다.
- 카테고리가 국가·언어별로 다를 수 있으므로 실제 선택 가능한 항목을 확인한다.
- 중복 후보는 합법적인 별도 지점·부서·독립 업체인지 구분해 정리한다.
  이름·주소가 비슷하다는 이유만으로 삭제·폐업·통합 처리하지 않는다.

## 3. 시간·연락·방문 경로

- [ ] [특별 영업시간](https://support.google.com/business/answer/6303076?hl=en)으로 처리할
      공휴일·임시 변경과 평상시 일정을 구분한다. 날짜·요일·시간대를 확인한다.
- [ ] 수업별 일정이나 예약제 사업의 시간을 임의로 일반 영업시간으로 바꾸지 않는다.
- [ ] 전화·사이트·예약 링크가 실제 업체로 이어지는지 확인한다.
      전화 걸기나 시험 예약을 만들지 않고도 가능한 링크·화면 점검부터 수행한다.
- [ ] 공식 사이트에 방문 안내, 교통·주차, 제공 서비스, 문의 방법이 찾기 쉬운지 본다.
- [ ] 지점별 페이지는 실제로 다른 위치·서비스 정보를 담게 한다.
      존재하지 않는 지점이나 지역명만 바꾼 대량 페이지를 만들지 않는다.

## 4. 리뷰와 신뢰 정보

- [ ] 최근 리뷰의 반복 질문·불편 사항과 업체 답변의 정확성을 표본으로 확인한다.
- [ ] [리뷰 정책](https://support.google.com/contributionpolicy/answer/7400114)에 맞춰
      실제 경험에 대한 중립적 요청을 사용하고 보상·긍정 리뷰 선별 요청을 피한다.
- [ ] 허위 리뷰, 경쟁 업체 비방, 고객 개인정보가 포함된 답변을 작성하지 않는다.
- [ ] 프로필·사이트의 서비스 설명과 사진을 대조하고 오래된 안내의 수정안을 만든다.
      확인되지 않은 경력·자격·수상·평점·리뷰 수를 생성하지 않는다.

## 5. 결과와 재확인

- 로컬 순위는 [관련성·거리·인지도 등](https://support.google.com/business/answer/7091?hl=en)에
  영향을 받는다. 프로필 완성이나 리뷰 수만으로 상위 노출을 보장하지 않는다.
- 결과마다 `확인됨 / 개선 필요 / 미확인 / 해당 없음`과 근거 URL·확인일을 적는다.
  사용자 제공 자료와 공개 관측이 다르면 어느 값이 맞는지 임의로 결정하지 않는다.
- 수정안은 `항목 | 현재 값 | 제안 값 | 근거 | 우선순위`로 제공한다.
  전화 연결 실패·잘못된 위치처럼 고객 이용을 막는 오류를 먼저 다룬다.
- 권한이 있는 수정은 요청 범위에서 실행하고 [수정 상태](https://support.google.com/business/answer/3039617?hl=en)를 확인한다.
  저장 성공과 공개 반영을 구분하고, 심사 중이면 완료로 보고하지 않는다.
- 성과 비교는 같은 지역·장치·기간의 자료를 사용하며, 계절성과 관측 한계를 적는다.
  관리자 성과 데이터가 없으면 순위·예약·매출 증가를 측정한 것처럼 보고하지 않는다.
