# 경쟁사·키워드 갭·백링크 — 증거 기반 점검

공개 페이지의 내용 차이와 검색·링크 데이터의 차이를 구분한다.
도구나 계정이 없어도 공개 점검은 진행하되, 관측하지 않은 수치를 만들지 않는다.

## 1. 비교 범위와 입력

- [ ] 내 사이트와 비교할 경쟁사 2~5개, 핵심 상품·서비스와 고객 질문을 정한다.
- [ ] 직접 경쟁 업체와 검색 결과에서 경쟁하는 정보 사이트를 구분한다.
- [ ] 국가·지역, 언어, 장치, 검색엔진, 검색 유형, 기간을 기록한다.
      같은 조건끼리 비교하고, 맞출 수 없는 조건은 비교표의 제한으로 남긴다.
- [ ] 데이터 출처, 추출일, 필터, 행 제한, 도메인/하위 경로 범위를 기록한다.
- [ ] 이미 제공된 자료·연결된 권한을 활용한다. 계정 접근이 없으면 공개 페이지와
      사용자 제공 Search Console/SEO 도구 export로 가능한 범위부터 분석한다.

## 2. 공개 콘텐츠 갭

1. 대표 질문별로 내 페이지와 경쟁 페이지 URL을 짝짓는다.
2. 제목·본문·가격/조건·비교표·사례·저자·출처·갱신일·FAQ·행동 경로를 관찰한다.
3. 어떤 고객 질문이 빠졌는지, 자체 경험·데이터로 보강할 부분을 적는다.
4. 기존 글 보강·통합·새 페이지 중 필요한 작업을 고르고 담당 URL을 정한다.

**공개 내용 비교는 검색량·실제 유입·키워드 순위 갭의 측정이 아니다.**
검색 결과 표본은 조회 시점·위치·장치와 실제 확인한 결과만 남긴다.
한 번 보이지 않았다고 미색인, 유입 0, 순위권 밖이라고 단정하지 않는다.
경쟁사 문장·이미지를 복제하거나 같은 질문의 얇은 페이지를 대량 생성하지 않는다.

## 3. 데이터 기반 키워드 갭

- [ ] 내 사이트의 쿼리·페이지·클릭·노출·CTR·평균 게재순위를 확인한다.
      [Search Console 성과 보고서](https://support.google.com/webmasters/answer/7576553?hl=en)는
      해당 속성의 데이터다. 경쟁사 비공개 실적을 보여주는 자료가 아니다.
- [ ] 경쟁사 수치는 이용 가능한 SEO 도구 export 등의 출처를 명시하고,
      도구 추정 검색량·트래픽과 실제 Search Console 관측값을 분리한다.
- [ ] 국가·언어·장치·기간·검색 유형을 맞춘다. 언어 필터가 없는 자료는
      페이지/쿼리의 언어를 별도 분류하고 사용한 방법과 한계를 적는다.
- [ ] 누락 쿼리는 0으로 채우지 않는다. 표본·비공개 처리·행 제한 가능성을 확인한다.
- [ ] 브랜드/비브랜드와 정보 탐색/비교/예약·구매 의도를 나눠 URL에 매핑한다.
- [ ] 실무 관련성, 관측된 수요, 현재 페이지의 보강 가능성을 기준으로 우선순위를 준다.
      수요 데이터가 없으면 편집상 판단으로 표시하고 수치 기반 순위처럼 제시하지 않는다.

| 질문/쿼리 | 의도 | 내 URL | 경쟁 URL | 근거·조건 | 부족한 답변 | 다음 작업 |
|---|---|---|---|---|---|---|
| 실제 확인한 질문 | 정보/비교/전환 | URL/없음 | 관측 URL | 출처·기간·지역 | 관찰 내용 | 보강/통합/신규 |

## 4. 백링크 프로필

- [ ] 사용자 제공 Search Console Links 보고서나 사용 가능한 도구 export를 읽는다.
      [Google의 Links 보고서](https://support.google.com/webmasters/answer/9049606)는
      전체 링크 목록이 아닌 표본이며, 현재 사라진 링크도 포함될 수 있다.
- [ ] 출처 URL, 대상 URL, 앵커, 제공된 발견일/확인일, 도구명을 보존한다.
      링크별 행인지 도메인별 집계인지 구분하고 중복 제거 기준을 명시한다.
- [ ] 표본에서 핵심 랜딩 페이지 누락, 소수 도메인 편중, 관련 분야의 언급을 확인한다.
      총 링크·참조 도메인 수는 **제공된 데이터 범위의 수치**로만 보고한다.
- [ ] 영향이 큰 표본은 공개 원문을 열어 실제 링크·앵커·`rel`·대상 응답을 확인한다.
      데이터에 없는 `nofollow` 여부나 삭제 상태를 추정하지 않는다.
- [ ] 끊어진 대상 URL은 콘텐츠의 실제 후속 페이지가 있는지 확인해 복구안을 만든다.
      관련 없는 페이지나 홈페이지로 모든 링크를 일괄 리다이렉트하지 않는다.
- [ ] 다른 시점의 export를 비교할 때 수집 범위·도구·중복 기준을 맞춘다.
      표본에서 빠진 항목은 원문 확인 없이 '손실 링크'로 확정하지 않는다.

## 5. 실행 경계와 결과

- '유해성 점수'나 낯선 도메인만으로 패널티를 단정하지 않는다.
- 자동 disavow 목록 생성·제출을 기본 작업으로 두지 않는다.
  [Google의 disavow 안내](https://support.google.com/webmasters/answer/2648487?hl=en)에 따라
  상당한 인위적 링크와 수동 조치/가능성의 근거가 있는 경우에만 별도 검토한다.
- [링크 스팸 정책](https://developers.google.com/search/docs/essentials/spam-policies#link-spam)에
  어긋나는 순위 조작용 링크 구매·자동 링크 생성·과도한 상호 링크를 제안하지 않는다.
- 결과는 `확인됨 / 추정(도구 출처) / 미확인`과 근거 URL·날짜를 함께 적는다.
  권한 없는 대시보드의 수동 조치 상태는 미확인으로 남긴다.
- 사용자 요청에 포함된 분석·수정은 기존 권한 범위에서 진행한다.
  외부 업체 연락·계정 변경은 감사 요청만으로 실행하지 않는다.
- 최종 산출물: 상위 콘텐츠 갭, 링크 표본 이슈, 우선순위·대상 URL·재확인 방법.
  분석 데이터가 없으면 필요한 export 종류를 명시하고 공개 점검 결과는 먼저 제공한다.
