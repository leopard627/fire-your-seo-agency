# 콘텐츠 품질 — QRG·E-E-A-T 진단

**페이지가 독자의 목적을 충족하는지, 그 설명을 신뢰할 근거가 있는지** 점검한다.
Google의 공개 지침을 참고한 실무 진단이며 QRG 전체 평가 절차의 구현이 아니다.
E-E-A-T는 단일 순위 요소가 아니며, 공식 E-E-A-T 점수나 검색 순위 보장을 제공하지 않는다.
진단만 요청받으면 발견 사항과 개선안을 전달한다. 수정·발행·삭제는 요청된 작업 범위에서만 한다.

## 1. 입력과 표본

- 대상 URL·주요 독자·언어/지역·페이지 목적을 확인한다. 문맥으로 알 수 있는 것은 재질문하지 않는다.
- 사이트맵·URL 목록·Search Console의 페이지/검색어 데이터를 사용할 수 있으면 활용한다.
  접근 권한이 없으면 공개 페이지로 진행하고 트래픽·전환·검색 순위 원인은 미확인으로 남긴다.
- 큰 사이트는 홈페이지, 주요 서비스/상품, 정보성 글, 저자/소개 페이지를 포함해 표본을 잡는다.
  최신 글과 오래된 글, 유입 감소 페이지가 확인되면 함께 살핀다.
- 표본 URL·선정 이유·점검 날짜를 적는다. 대표 표본 결과를 사이트 전체 검사로 표현하지 않는다.

## 2. 목적과 사용자 도움

- [ ] 페이지마다 **누가 어떤 질문/과제를 해결하려고 방문하는지** 한 문장으로 적는다.
- [ ] 제목의 약속을 본문이 충족하는가? 다음 행동에 필요한 조건·절차·예외가 있는가?
- [ ] 핵심 답을 찾기까지 광고·반복 문구·불필요한 도입부가 방해하는가?
- [ ] 주장과 사례가 구체적인가? 다른 글의 재서술 외에 독자에게 도움이 되는 정보가 있는가?

누락을 지적할 때는 실제 문단과 해결되지 않는 질문을 짝지어 적는다.
예: “수강 대상은 있으나 선행 경험 필요 여부가 없어 입문자가 신청 가능 여부를 판단하기 어렵다.”
긴 글 자체를 목표로 삼지 않는다. 짧아도 목적을 충분히 달성하면 보완을 강요하지 않는다.

## 3. 경험·전문성·권위성·신뢰성

페이지의 주제와 위험에 맞게 판단한다. 체험담과 전문적 조언에 같은 자격 기준을 적용하지 않는다.
건강·금융·안전에 영향을 주는 YMYL 조언은 해당 분야의 적절한 근거와 검토 여부를 특히 확인한다.

| 요소 | 관찰할 근거 | 진단 시 구분 |
|---|---|---|
| 경험 | 직접 수행한 과정·조건·결과, 원본 사진/기록 | “경험이 없다”와 “페이지에서 증거를 찾지 못했다” |
| 전문성 | 주제에 맞는 경력·자격·검토자, 주요 주장과 출처 | 자격 표기 여부와 해당 주장에 대한 검증 여부 |
| 권위성 | 관련 분야의 독립적인 소개·인용·평판 | 자사 홍보문과 독립 출처, 동명이인과 실제 당사자 |
| 신뢰성 | 책임 주체·연락처, 사실 정확성, 출처·이해관계 | 확인된 오류와 자료 부족으로 판단할 수 없는 사항 |

- [ ] 핵심 주장 일부를 원출처와 대조하고 출처가 실제로 그 주장을 뒷받침하는지 확인한다.
- [ ] 저자/운영자 정보가 실제 내용과 연결되는가? 실명·자격을 임의로 만들어 채우지 않는다.
- [ ] 구매·예약 페이지라면 가격 조건·문의·취소/환불 안내가 독자의 판단에 충분한가?
- [ ] 제품 체험·평가라면 제공/협찬 등 이해관계와 평가 방식이 필요한 만큼 드러나는가?
- [ ] 평판을 조사하면 검색어·출처·확인 날짜를 기록한다. 외부 언급 부재를 부정적 평판으로 보지 않는다.

증명되지 않은 경력·고객 후기·체험 사진을 생성해 신뢰성을 보완하지 않는다.
보완안은 “운영자가 제공할 실제 근거”와 “현재 근거로 작성 가능한 문안”으로 구분한다.

## 4. 중복·빈약·낡은 콘텐츠

- **중복 후보**: 같은 질문을 다루는 URL을 묶고 고유 사례·대상·목적 차이를 비교한다.
  공통 안내문이나 같은 주제라는 이유만으로 중복 또는 검색 페널티라고 단정하지 않는다.
- **빈약한 답변**: 글자 수보다 독자가 해결하지 못하는 질문과 부족한 근거를 기록한다.
  노출/유입이 적다는 사실만으로 콘텐츠 품질이 낮다고 결론내리지 않는다.
- **낡은 정보**: 가격·일정·제도·도구 설명의 확인 가능한 원출처와 현재 내용을 대조한다.
  오래된 게시일만으로 오류로 보지 않으며, 실질적 수정 없이 날짜만 바꾸지 않는다.
- **유사한 대량 글**: 지역명/상품명만 바뀐 페이지라면 독자별 추가 가치가 있는지 확인한다.
  AI 사용 여부나 탐지기 점수를 품질 판정의 근거로 삼지 않는다.

페이지별로 유지 / 근거 보강 / 내용 갱신 / 통합 검토 중 적절한 개선안을 제시한다.
통합·삭제·noindex는 독자 목적, 고유 정보, 확인 가능한 유입/링크를 고려한 제안으로 남긴다.
진단 요청만으로 실행하거나 전체 사이트를 일괄 정리하지 않는다.

## 5. 보고 형식

먼저 핵심 발견과 우선 개선할 항목을 요약한 뒤 URL 단위 표를 제공한다.
점검하지 않은 페이지나 접근할 수 없는 근거는 **미확인**으로 표시한다.

| 대상 URL | 발견 사항 | 근거 URL·문단/관찰 | 영향·우선순위 | 구체적 개선안 | 불확실성·추가 입력 |
|---|---|---|---|---|---|
| 실제 점검 URL | 관찰된 문제 | 재확인 가능한 근거 | 독자가 겪는 문제 중심 | 수정 위치·필요 자료 | 확인하지 못한 이유 |

- 확실한 사실 오류·오해를 유발하는 조건을 먼저, 누락된 답변과 근거 보완을 다음에 다룬다.
- 잘된 페이지의 재사용 가능한 장점도 짧게 기록한다.
- 수정까지 요청된 경우 수정 전/후와 검증된 출처를 남긴다. 확보하지 못한 근거는 만들어 넣지 않는다.
- 표본 수·확인 날짜·사용한 자료·미확인 범위를 명시하고 순위 변화의 인과관계를 단정하지 않는다.
